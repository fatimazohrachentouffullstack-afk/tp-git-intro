# TP Git Intro

## 1. Nom du projet

TP Git Intro

## 2. Objectif du projet

Apprendre à utiliser Git et GitHub pour gérer les versions d'un projet web et suivre les modifications.

## 3. Technologies utilisées

* HTML
* CSS
* Git
* GitHub

## 4. Instructions pour ouvrir la page

1. Télécharger ou cloner le projet.
2. Ouvrir le dossier du projet.
3. Double-cliquer sur le fichier index.html pour ouvrir la page dans un navigateur.

## 5. Évolutions enregistrées dans Git

* Création de la page HTML.
* Modification du contenu de la page.
* Ajout d'un nouveau paragraphe dans index.html.
